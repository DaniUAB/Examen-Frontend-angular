# Frontend Angular - Sistema de Empleados

Frontend desarrollado en Angular para gestión de empleados con conexión a API Laravel.

## 🚀 Características

- **Interfaz moderna y responsive** para gestión completa de empleados
- **Formulario reactivo** para crear nuevos empleados con validación
- **Tabla dinámica** que muestra todos los empleados registrados
- **Comunicación HTTP** con backend Laravel mediante servicios
- **Manejo de estados** (loading, éxito, error)
- **Diseño profesional** con estilos CSS modernos

## 📱 Funcionalidades

### Gestión de Empleados
- ✅ Listar todos los empleados
- ✅ Crear nuevos empleados
- ✅ Validación de formularios
- ✅ Formateo automático de salarios
- ✅ Actualización en tiempo real de la lista

## 🛠️ Tecnologías Utilizadas

- **Angular 17+** - Framework principal
- **TypeScript** - Lenguaje de programación
- **RxJS** - Manejo de programación reactiva
- **HTTP Client** - Comunicación con API
- **CSS3** - Estilos y diseño responsive
- **Angular Router** - Navegación SPA

## 📦 Instalación y Uso

```bash
# 1. Clonar el repositorio
git clone https://github.com/DaniUAB/Examen-Frontend-angular.git
cd Examen-Frontend-angular

# 2. Instalar dependencias
npm install

# 3. Ejecutar servidor de desarrollo
ng serve

# 4. Abrir en el navegador
# http://localhost:4200
